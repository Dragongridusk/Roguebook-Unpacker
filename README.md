## 📂 Data Extraction Workflow

Follow the numbered sequence to unleash the full power of **Roguebook Unpacker**:

1. **Initialize** – launch the utility with `python unpacker.py`.
2. **Select Target** – point to the `Roguebook` installation directory.
3. **Configure** – edit any of the four `.cfg` files to match your preferences.
4. **Execute** – press the bound hotkey or run `python unpacker.py --run`.
5. **Review** – find the extracted bundles in the `output/` folder, ready for your next project.

Each step is logged to `logs/run_2026-10-30.txt` for traceability.
